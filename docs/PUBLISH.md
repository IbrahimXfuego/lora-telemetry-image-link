# Publish with drag and drop

1. Download and extract `LoRa-Telemetry-Image-Link.zip`.
2. On GitHub, select **New repository**.
3. Name it `lora-telemetry-image-link` and select **Public**.
4. Suggested description: `Bidirectional LoRa telemetry and JPEG image transfer with ESP32-CAM, ESP8266, CRC, selective retries and a Python dashboard.`
5. Leave GitHub's README, .gitignore and license initialization options empty; the package already includes project files. Choose a license separately after confirming contributor preferences.
6. Click **Create repository**, then **uploading an existing file** (or **Add file → Upload files**).
7. Open the extracted project folder. Drag its **contents** into GitHub: `README.md`, `firmware/`, `dashboard/`, `docs/`, `tests/` and `.gitignore`. Do not upload only the ZIP or nest the whole project under an extra outer folder.
8. The browser uploader does not filter your selection using `.gitignore`. Do not select `.venv`, `__pycache__`, generated captures or private configuration if you created these after extraction.
9. Use commit message `Add LoRa telemetry and image transfer project`, then commit.
10. Check that the README, wiring diagram and sketch folders render correctly.
11. Add the project collaborator's preferred name/roles and real photos or demo links when available.
12. Copy the repository URL into your portfolio project's GitHub field.

Suggested topics: `lora`, `ra-02`, `esp32-cam`, `esp8266`, `telemetry`, `arduino`, `flask`, `image-transfer`.

Public source code is available to view; this does not automatically grant an open-source license. This repository also does not host the USB-connected dashboard: run Python locally to use it with hardware. The public portfolio can link to it and show screenshots/videos.
